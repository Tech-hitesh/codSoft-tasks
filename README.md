tasks done for internship 


1. Number Guessing Game

Description: This is a simple console-based game where the computer randomly selects a number within a given range (e.g., 1 to 100), and the user tries to guess it.

What You Implemented:

Used a random number generator to select the target number.

Took user input using a loop until they guessed correctly.

Provided feedback on whether the guess was too high or too low.

Kept track of the number of attempts taken to guess correctly.

Optionally allowed the user to play again.


Skills Used:

Loops

Conditional statements

Random module

Input/output operations

2. Student Grade Calculator

Description: This project allows users to input marks for different subjects, calculates the total, average, and assigns a grade based on the percentage.

Used if-else conditions to assign grades like A, B, C, etc.

List or individual variables for subject marks

Arithmetic operations

Conditional logic
